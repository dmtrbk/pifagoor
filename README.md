# Driller Machine Master (Pifagoor) — Drill Angle Calculator

Расчёт угла бурения шпура **b**, чтобы попасть в уже пробурённый шпур **a**.

Горизонт чертят лазерным уровнем. Угол ставят на **b**, целимся в **a**.

## На телефоне

Откройте в Chrome:

**https://dmtrbk.github.io/pifagoor/**

Или файл [`drill-angle-pro.html`](drill-angle-pro.html).

Чтобы закрепить как приложение:

1. Откройте ссылку в Chrome на Android.
2. Меню → **Добавить на главный экран**.
3. В поле программа работает и без интернета.

## Как считать

1. Впишите длины **a** и **b** (метры) и высоты устьев **ha**, **hb** от лазера (сантиметры). Ниже горизонта — минус.
2. Выберите провис:
   - **По длине a** — с дуги по длине каждого шпура.
   - **По забойке** — смотрите в шпур a (вижу забойку / верх / низ / не вижу).
   - **Идеальный** — без поправок на провис.
3. Угол снизу экрана — его ставите на шпур **b**.

Формула:

```
h = ha − hb − sa + sb
α = arctg(h / b)
```

`sa` — уход дна шпура a (вниз плюс).  
`sb` — провис шпура b: его тоже добавляем, чтобы целиться выше.

Длины в метрах, высоты и провис в сантиметрах.

## Дуга провиса

Вкладка **Дуга** — одна кривая на a и b. До первой точки провис 0.

Замеры по умолчанию (штанги 1 м, Ø 40 мм, горизонтальное бурение):

| Длина | Провис |
| --- | --- |
| 8 м | 0 см |
| 12 м | 3 см |
| 14 м | 5 см |
| 16 м | 9 см |

Точки можно править. Браузер запоминает их на этом устройстве.

## На компьютере

Откройте `drill-angle-pro.html` в браузере или:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем http://127.0.0.1:8765/drill-angle-pro.html

В `src/` лежит черновик на Vite/React; для телефона он не нужен.
